## 3. What the finished library should contain [RESEARCH REC]

External research (message-house frameworks, Dunford positioning, Schwartz awareness stages, PR boilerplate conventions, sales-enablement objection playbooks, 2024–26 "single source of truth for AI" guidance — sources on file) supports the planned structure, with these refinements:

**Per offer:** verified offer truth (with last-verified dates per fact) · conversion strategy note (awareness-stage entry point) · one-line (problem → solution → result; no features, no proof) · short ~40–75 words (max 2–3 elements: description + one differentiator + one credibility marker; one specific number) · long ~125–225 words (promise → mechanism → proof → CTA; the only length that unpacks all pillars) · soft CTA / direct CTA / existing-member CTA · objections + responses, each paired with proof · proof available (tagged to the claim it supports) · source links · usage guidance (which length + CTA per channel and warmth).

**Library-level (once, not per offer):** voice rules pointer (do/don't pairs, not prose) · approved + banned phrase lists · proof index · objection-bank format (objection / real concern beneath it / response / proof) · routing table (channel × warmth → length + CTA) · versioning block (owner: Wanda; locked vs. living sections; changelog; review cadence — monthly fact hygiene, quarterly strategic).

**Three principles that shape the build:**
1. **One spine, three zoom levels** — the one-liner is the roof alone; short adds the strongest pillar + one proof; long unpacks everything. Never three separate messages.
2. **Awareness shifts the entry point, not the promise** (Schwartz): problem-aware lead for cold contexts, offer-first lead for warm — same spine.
3. **CTA temperature ladder**: colder traffic → softer CTA; the soft/direct/existing-member triad is a sound synthesis, not a named published framework — labeled accordingly.

**Guardrail [FABLE INFERENCE, per CLAUDE.md Rule 3]:** none of this overwrites Wanda's truth. Where generic best practice says "lead with a quantified result," Wanda's buyer reads FTC scam literature and distrusts hype-register claims — Truth Over Hype is the conversion mechanism. Research shapes the *containers*; Wanda's sources fill them.
