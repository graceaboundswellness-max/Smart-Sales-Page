# YT → Blog Repurposer

Turns one finished YouTube script or transcript into one publish-ready blog post for WandaLambert.com — built to rank, to get quoted by AI engines, and to route the reader to a current offer.

## Start here

Read **`references/workflow.md`** and follow it start to finish. It carries the absolutes, the nine steps, and the output format. Everything else is the detail those steps point at.

One rule matters enough to state twice: **offers, prices, and client-facing URLs come only from the live SEND A LINK sheet, quoted before the CTA is written.** The full rule is in the workflow.
